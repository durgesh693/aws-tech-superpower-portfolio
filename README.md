# Durgesh Maurya — Personal Portfolio & Engineering Showcase

A personal portfolio built for **Durgesh Maurya** (Data Science Student, Machine Learning Enthusiast, and AI Developer). Built with **Next.js 15**, **React 19**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

---

## 🏗️ Architecture & Folder Structure

/
├── app/ # Next.js 15 App Router pages & metadata
│ ├── globals.css # Custom Tailwind tokens & glassmorphism
│ ├── layout.tsx # Root layout with JSON-LD & theme providers
│ ├── page.tsx # Assembled single-page application
│ ├── error.tsx # Error boundary component
│ ├── loading.tsx # Fallback loader
│ ├── not-found.tsx # Custom 404 page
│ ├── robots.ts # Automated SEO crawler configuration
│ └── sitemap.ts # Dynamic XML sitemap generator
├── components/
│ ├── graphics/ # Custom SVG/CSS vectors (AI & Neural Net)
│ ├── layout/ # Sticky Navbar, Drawer, Footer
│ ├── sections/ # Core section components (Hero, About, Skills, etc.)
│ └── ui/ # Reusable UI primitives (Button, Card, Modal, etc.)
├── data/ # Single-source configuration data layer
│ ├── certifications.ts # Verified certificates & verification links
│ ├── education.ts # Academic degree timeline
│ ├── profile.ts # Personal information, bio, metrics
│ ├── projects.ts # 5 ML Case studies with problem/solution splits
│ ├── site-config.ts # Navigation links & global SEO metadata
│ └── skills.ts # Categorized technology stack
├── hooks/ # Throttled scroll & active navigation hooks
├── lib/ # Utility classes & contact form validation
├── public/ # Static assets, favicon, resume placeholder
└── types/ # Strict TypeScript interfaces
